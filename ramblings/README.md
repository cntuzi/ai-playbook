# Ramblings · 碎碎念

关于业务怎么变化、人与智能体怎么协作的一些想法。这里保留相对成形的判断、还在发散的讨论，以及一路改过来的旧稿。

目前主要围绕两个问题：

1. 如何用横向场景、纵向领域和时间变化统一表达业务；
2. 如何让组织、人和智能体基于这些业务事实协同运行，并进一步形成 AI Native 生产系统。

目录按内容和进展组织。V1 和配套文档放在前面，仍在发散的问题进入讨论稿，已经被后续文档吸收的内容保留为演进记录。正文保留原来的标题和术语，方便接着读、接着改。
